# PCL 下载功能修复补丁

PCL（含官方版与社区版 CE）在新版本里移除了「Minecraft 下载 / 补全 / 整合包安装」功能。
这里的补丁把功能恢复回来，**不改你的存档、不上传任何信息**。

## 下载

到 [Releases](../../releases/latest) 页面下载对应你所用启动器的那个 zip：

| 你用的是 | 下载 |
| --- | --- |
| 官方 PCL（Plain Craft Launcher 2） | `PCL2FIX_v5.2.4.zip` |
| PCL 社区版 CE（PCL2_CE_x64） | `PCL2CEFIX_v1.5.zip` |

不确定是哪个？看启动器标题：带 `CE` 字样的用 CE 版，其余用官方版。

## 怎么用（官方 PCL）

1. 完全退出 PCL（右下角托盘里的图标也要退）
2. 解压后把 `PCL2FIX.exe` 放进 PCL 文件夹，双击
3. 看到 `[√] 补丁写入成功，复查通过。` 就重新打开 PCL

好了以后：

- 原版游戏可以直接下载
- 整合包需要把压缩文件拖进 PCL 窗口进行下载

## 怎么用（PCL CE）

1. 完全退出 PCL CE
2. 解压后把 `PCL2CEFIX.exe` 放进 CE 文件夹，双击
3. 看到 `[√] 解锁成功，复查通过。` 就重新打开 CE

好了以后：

- 可以直接下载游戏和整合包。整合包需要把压缩文件拖入 CE 窗口进行下载安装

## 更新后自动修复（可选）

PCL 更新会把 exe 整个换掉，补丁随之消失。包里另附了启动器：

- 官方版：`启动PCL（自动修复）.bat`
- CE 版：`启动CE（自动修复）.bat`

把它们放进对应文件夹，以后从这个 bat 启动（可发送快捷方式到桌面）。
每次启动前会静默检查一遍，补丁在就直接开，被更新覆盖了会自动补回。

## 说明

- 补丁按**程序结构**识别，不认版本号：作者重新编译后（正式版 / 快照版）通常仍然有效。
- 认不出的版本会**直接拒绝、一个字节都不改**，并提示把 exe 交给作者适配。
- 修改前会自动备份为 `*.pclfix.bak.<哈希前8位>`。
- 压缩包里附完整源码（C# 5，可用系统自带 `csc` 编译核对）。
